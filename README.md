# ZEWÁ Reformas · Landing

Sitio estático (HTML, CSS y JavaScript, sin dependencias ni paso de compilación).

- `index.html`: portada.
- `servicio.html?s=<servicio>`: página de cada servicio (18 en total, generadas desde `assets/app.js`).
- `assets/`: estilos y lógica compartidos.
- `img/`: fotografías.

Despliegue: Vercel, sin configuración (framework "Other", sin comando de build, directorio raíz `/`).
